# Power-BI

Analysis of various datasets showcasing Power BI use.

The actions carried out include:

- Power query/ DAX
- Data transformation
  - Split column
  - Remove column
  - Create column
- Data analysis
- Conditional formatting
- Filters
- Searches/ Extractions
- Visualisations

The analysed data were transformed into visualisations dashboards to give a snapshot of key information. 

The data analysis and raw data are available on the Power BI sheets.
